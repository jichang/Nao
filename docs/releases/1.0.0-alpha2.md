# Nao 1.0.0-alpha2 release notes

- Release date: Unreleased
- Milestone: R4
- Owners: @jichang

## Summary

Draft notes for Nao's second alpha prerelease. This version advances the package
set and remains intended for evaluation without a compatibility or support guarantee.

## Added

None

## Changed

All Nao projects inherit package version `1.0.0-alpha2`. Generated extension
projects reference the same Nao package version.

## Fixed

None

## Breaking changes

None

## Security

The existing fail-closed security boundaries and protected publication gates remain required.

## Upgrade and rollback

Fresh installation only. Development snapshots and prereleases have no supported
upgrade path. Back up authoritative data before evaluation; rollback requires
restoring the pre-deployment backup.

## Validation

Publication requires the clean solution build, full supported test surface,
compatibility, migration, evaluation, security, performance, documentation,
package-content, and clean-consumer gates. This draft does not claim publication qualification.

## Supply-chain evidence

The protected workflow must retain package digests, SPDX SBOMs, provenance and
SBOM attestations, dependency-lock identity, vulnerability results, license review,
and the OIDC Trusted Publishing identity. No NuGet package signatures are claimed.

## Known limitations

The [capability inventory](../capabilities.md) remains authoritative.
No stable compatibility, support, or multi-region guarantee is claimed.
