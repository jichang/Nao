# Nao 1.0.0 release notes

- Release date: Unreleased
- Milestone: R4
- Owners: @jichang

## Summary

Draft notes for Nao's first supported release. The project remains unreleased until the protected publication workflow completes.

## Added

Initial platform foundations for governed agents, tools, knowledge, evaluation, distributed runtime, formal reasoning, operations, extensions, developer workflows, the protected release process, and the selected production integration set.

## Changed

None. This is the first supported release and has no supported predecessor.

## Fixed

None. This is the first supported release.

## Breaking changes

None

## Security

Production profiles require authenticated identities, restricted tools, isolated untrusted work, durable authoritative state, protected administration, and host-owned trust roots.

## Upgrade and rollback

Fresh installation only. Development snapshots are unsupported inputs; rebuild or explicitly transform development data using the applicable migration guides. Rollback requires restoring the authoritative pre-deployment backup.

## Validation

The final release record must include the clean solution build, full supported test surface, compatibility, migration, evaluation, security, and performance gates, strict generated documentation, executable examples, deployment validation, clean-consumer installation, vulnerability scans, license review, and artifact verification.

## Supply-chain evidence

The protected workflows attach signed package and image digests, SPDX SBOMs, provenance and SBOM attestations, dependency-lock identity, vulnerability results, license review, native dependency changes, and signing identity.

## Known limitations

The final record must link every remaining limitation from the capability inventory and R4 roadmap. No multi-region guarantee is claimed.
